# Optional piano libraries

Settings → Audio → Sound fonts offers the following SF2 downloads for the
Studio and Native engines. Choose Download to install and select a piano.
The bundled GeneralUser GS bank supplies instruments the piano bank does not
contain. These optional libraries are not included in Pliage's installer.

| Piano | Upstream file | Approximate installed size |
|---|---|---|
| Steinway Model B | Dore Mark's NY S&S Model B-v5.2.sf2 | 237 MiB |
| Nice Steinway Lite | Nice-Steinway-Lite-v3.0.sf2 | 71 MiB |
| Fazioli F308 | Dore Mark's Fazioli F308-v2.6.sf2 | 299 MiB |
| Mason & Hamlin Model A | MasonHamlin-A-v7.sf2 | 324 MiB |
| Salamander Yamaha C5 | Yamaha-C5-Salamander-JNv5.1.sf2 | 592 MiB |

The downloads use a pinned revision of the
[Soundfonts4U preservation archive](https://huggingface.co/datasets/projectlosangeles/soundfonts4u/tree/b8a0526c20bd73e7d009f7e2d94ca6abbccd9a2d).
Its README preserves John Nebauer's original descriptions and credits.
Dore Mark sampled the Model B and Fazioli; John Nebauer made the SF2 versions.
Nice Steinway uses Anthony Deaton's Philharmonic project / University of Iowa
samples, with John Nebauer's adaptations. Its embedded copyright field names
CC BY-ND 3.0. Mason & Hamlin is sampled by Dore Mark and adapted by John Nebauer;
its embedded terms prohibit commercial resale or packaging. Pliage links to the
existing archive downloads instead of packaging these samples. Each library's
Source & terms button opens the preserved documentation. Retain the embedded
credits and terms if you copy a library.

The mirror labels its collection CC BY-NC-SA 4.0. This collection label does
not replace the individual sample authors' terms. Check those terms before
commercial use, modification or redistribution; a free download is not a
blanket permission to bundle samples in another product.

Salamander's original Yamaha C5 recordings are by Alexander Holm, licensed
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Pliage offers John
Nebauer's 15-layer SF2 adaptation, rather than the larger 16-layer FreePats
conversion. The original SF2/SFZ downloads and credits are available from
[FreePats](https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html).

## Bösendorfer

[Realistic Piano](https://www.realisticpiano.com/) is a paid Bösendorfer Imperial
SF2 library by Giuseppe Mariotti. The Get library button opens its vendor page.
After purchase, extract the ZIP and use Import .sf2 or .sf3; the imported piano
then appears as a selectable sound set. Pliage does not purchase or redistribute
this library. The vendor also includes a historical 1828 Bösendorfer fortepiano.

## Roland FP-90X

The [FP-90X](https://www.roland.com/global/products/fp-90x/) uses Roland's
PureAcoustic Piano Modeling engine for its principal piano tones. No verified
FP-90X SF2 download was found, so it is not listed as a downloadable instrument.
A sampled soundfont cannot reproduce the complete modeling engine.
